# 👁️ Eye Tracker Keyboard

Прототип системы управления виртуальной клавиатурой с помощью взгляда.
Работает на Python + OpenCV + Pygame.  
Тестировалось на Mac M2 и инфракрасной камере HBVCAM-1914S V44.

---

## 🚀 Запуск

```bash
git clone https://github.com/<your_username>/eye-tracker-keyboard.git
cd eye-tracker-keyboard
pip install -r requirements.txt
python3 eye_keyboard.py
